# Khallof Market — إصدار PostgreSQL للنشر

تطبيق ويب عربي للزبائن ولوحة إدارة محمية. يستخدم PostgreSQL لحفظ المنتجات والطلبات والإعدادات، وتُحفظ صور المنتجات في قاعدة البيانات لتجنب ضياعها مع إعادة تشغيل خدمة الويب.

## النشر على Render
1. ارفع جميع محتويات هذا المجلد إلى جذر مستودع GitHub `khallof-market` واستبدل الملفات القديمة.
2. في Render اختر **New → Blueprint** ثم اربط المستودع. سيقرأ Render ملف `render.yaml` وينشئ خدمة الويب وقاعدة PostgreSQL.
3. راجع الخطة المجانية والتوفر في حسابك ثم وافق على إنشاء الموارد.
4. بعد النشر افتح صفحة الخدمة ثم **Environment** وخذ قيمة `ADMIN_PASSWORD` التي ولّدها Render؛ لا تشاركها مع أحد. اسم المستخدم `admin`.
5. افتح رابط الخدمة، ثم أضف `/api/health` للتأكد من ظهور `ok: true`.

## تنبيهات قبل الاستخدام التجاري
- الخطة المجانية قد تتوقف مؤقتاً عند عدم الاستخدام، وقد تتغير حدودها وتوفر قاعدة البيانات حسب سياسة Render الحالية. لا تعتمد عليها وحدها لمتجر حقيقي قبل اختبار النسخ الاحتياطي والاستعادة.
- تم تخزين صور المنتجات كبيانات داخل PostgreSQL.
- الجلسات الإدارية تستخدم مخزن الذاكرة الافتراضي؛ قد تحتاج إلى تسجيل الدخول مجدداً بعد إعادة تشغيل الخدمة.
- هذه نسخة أولية: اختبر الطلبات والمخزون والصلاحيات، وغيّر كلمة مرور الإدارة قبل مشاركة الرابط.
- التطبيق حالياً Web/PWA ويمكن تثبيته من متصفح Android عند توفر HTTPS؛ لم يتم إنشاء APK أصلي بعد.
