# Khallof Market — نسخة أولية قابلة للتشغيل

## ما تتضمنه
- واجهة عربية للزبائن: عرض وبحث وتصنيف المنتجات، سلة، عنوان توصيل، وطلب مع الدفع نقداً عند الاستلام.
- لوحة إدارة محمية: الطلبات وتغيير حالتها، إضافة المنتجات ورفع صورها وإخفاؤها، وإعداد أجور التوصيل والعملة.
- قاعدة بيانات SQLite تحفظ المنتجات والطلبات.
- تطبيق ويب تقدمي PWA يمكن تثبيته من Chrome على أندرويد عند نشره على عنوان HTTPS.

## التشغيل على الكمبيوتر
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في الطرفية وشغّل: `npm install`
3. شغّل: `ADMIN_USER=admin ADMIN_PASSWORD='ضع-كلمة-مرور-قوية' SESSION_SECRET='قيمة-سرية-طويلة' npm start`
4. افتح `http://localhost:3000`.

بيانات الدخول الافتراضية للتجربة فقط: `admin` / `admin12345` — غيّرها قبل أي استخدام حقيقي.

## التثبيت على أندرويد
بعد نشر المشروع على استضافة تدعم Node.js مع HTTPS، افتح رابط المتجر في Chrome ثم اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

## مهم قبل الإطلاق الحقيقي
هذه نسخة MVP أولية وليست جاهزة للنشر العام قبل إعداد الاستضافة وHTTPS ونسخ احتياطي دوري، وتغيير كلمات المرور والأسرار، وضبط سياسة الخصوصية وحماية إساءة الاستخدام. قاعدة البيانات محلية على الخادم؛ لا تضع المشروع على استضافة ملفات ثابتة فقط. الإشعارات الفورية الحقيقية، خرائط تحديد العنوان، وتغليف APK أصلي ليست مفعّلة في هذه النسخة.
